Installation Steps
1
Install XAMPP
Download from apachefriends.org. Install on your Windows/Mac/Linux computer. Start Apache and MySQL from the XAMPP Control Panel.
2
Copy Project Folder
Extract the restopos.zip file. Copy the entire restopos/ folder into C:\xampp\htdocs\ on Windows or /Applications/XAMPP/htdocs/ on Mac.
3
Import Database
Open http://localhost/phpmyadmin in your browser. Create a new database named restopos. Click Import → choose database.sql → click Go.
4
Configure Database Connection
Open includes/config.php in a text editor. Set DB_USER and DB_PASS to match your MySQL credentials (default: root / blank password).
5
Open the Application
Go to http://localhost/restopos/ in your browser. The login page appears. Use admin / admin123 to log in as administrator.
6
Customise for Your Restaurant
Go to Settings → update your business name, address, phone, and tax rates. Add your menu items in Menu Manager. Add your staff in Employees. You are ready to start billing.
